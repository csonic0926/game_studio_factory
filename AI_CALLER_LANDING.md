# Compatibility landing — Game AI Factories

The repository is now **Game Studio Factory**:

```text
Game Studio Factory   = autonomous whole-game operator
Game AI Factories     = specialist capabilities
```

Start at [`STUDIO_CALLER_LANDING.md`](STUDIO_CALLER_LANDING.md).
Every proposed game-design idea, including AI-generated mechanisms and later
iterations, must actually receive `idea-factory` inquiry with recorded reasons
and open questions. This applies even when the whole direction is settled; see
[the per-idea workflow](idea/docs/PRODUCT_DEFINITION_WORKFLOW.md#every-idea-receives-substantive-inquiry).

This filename remains so existing linked repos and callers do not break. The
specialist folders and their entry contracts remain stable:

- `idea/` → `idea-factory`
- `gameplay/` → `gameplay-factory`
- `story/` → `game-story-factory`
- `asset/` → `asset/docs/AI_CALLER_LANDING.md`
- `sound/` → `sound/docs/AI_CALLER_LANDING.md`
