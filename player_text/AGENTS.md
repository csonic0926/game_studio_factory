# Shared player-text workflow ownership

This is a cross-Factory workflow, not another content-owning Factory. It owns
text inventory, language-production guidance and exact-output evidence checks.
Read WORKFLOW.md; external callers use CONTRACT.md and player_text.py directly.

Game-specific inventories, text, readings and reviews belong in the exact target
project, never here. Do not scan sibling games. Never change game rules, canon,
locales, permissions or accepted history to make a wording check pass.
The tool proves evidence coverage/freshness, not human comprehension or acceptance.
v3 applicability is explicit in the reviewed design; v1/v2 may call the workflow
independently without adopting new Factory approval or completion semantics.
