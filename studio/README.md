# Game Studio Factory

Autonomous whole-game operator above the specialist Game AI Factories.

Start with:

- [`AGENTS.md`](AGENTS.md) — hard operator invariants;
- [`docs/AI_CALLER_LANDING.md`](docs/AI_CALLER_LANDING.md) — user/AI entry;
- [`docs/STUDIO_FOUNDATION.md`](docs/STUDIO_FOUNDATION.md) — baseline, ratchet,
  research, scale-out, and scale-up semantics.

The v0 folder establishes authority, state schemas/templates, and the installed
`game-studio-factory` skill. It does not yet contain a persistent scheduler or
baseline compiler/checker; see the explicit limitation in the landing contract.
